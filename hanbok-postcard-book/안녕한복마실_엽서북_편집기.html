사용법 (Chrome 또는 Edge 권장)
  1. 빈 사진 칸을 클릭하거나 사진 파일을 칸 위로 끌어다 놓으세요. 사진 한꺼번에 넣기로 여러 장을 고르면 빈 칸에 순서대로 들어갑니다.
  2. 사진 위에서 드래그하면 위치 이동, 마우스 휠(또는 ＋/－ 버튼)로 확대·축소, 더블클릭으로 교체됩니다. 빨간 저해상도 표시가 뜨면 인쇄 시 흐릴 수 있습니다(150dpi 미만).
  3. 글자는 클릭해서 바로 고칠 수 있습니다. 작업 내용은 이 브라우저에 자동 저장됩니다.
  4. 표지 PDF 저장 / 내지 PDF 저장 → 인쇄 창에서 대상 PDF로 저장, 여백 없음, 배율 100%, 배경 그래픽 체크. 용지는 104×154mm(도련 2mm 포함)로 자동 설정됩니다.
